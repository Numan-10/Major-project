# 🏠 Airbnb Clone

**Live Link**: [Explore the Project Here!](https://wanderlust-gy46.onrender.com/listings)

Welcome to the **Airbnb Clone**! This project captures the core functionalities of Airbnb, enabling users to browse, list, and manage rental properties effortlessly. Crafted with a focus on both functionality and user experience, this clone offers insights into full-stack development for online rental marketplaces.

---

## ✨ Key Features

- 🔐 **Authentication & Authorization**: Secure sign-up and login, allowing personalized access to user accounts.
- 🏡 **Listings Management**: Easily add, edit, or remove property listings to suit your needs.
- 🗺️ **Interactive Map Integration**: Visualize property locations on an interactive map for intuitive searching.
- 📱 **Fully Responsive Design**: Optimized for seamless access across all devices.
- 📸 **Image Management**: Integrated with Cloudinary for quick and efficient image uploads.
- ⚙️ **Optimized User Interface**: Carefully crafted with usability and aesthetic appeal in mind.

---

## 🛠️ Tech Stack

- **Frontend**: EJS templating for dynamic, adaptable user interfaces.
- **Backend**: Node.js and Express for robust API and server functionality.
- **Database**: MongoDB, managing users and property data.
- **Cloudinary**: Image hosting and management.
- **Mapbox**: Interactive maps to visually mark listing locations.
